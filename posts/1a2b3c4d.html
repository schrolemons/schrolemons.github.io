Hexo-Butterfly 聊天界面魔改：DeepSeek 风格文字瞬间

发表于2026-06-05|更新于2026-06-05
|字数总计:1938|阅读时长:8分钟|阅读量:

本篇教程基于 Hexo 6.x & Butterfly 4.x，在参考 meuicat 的聊天记录页教程 的基础上，完全重构为 DeepSeek 网页版 AI 聊天风格。

最终效果

  • 左侧会话列表（类比 DeepSeek 的历史对话侧栏）
  • 右侧聊天主区：用户消息蓝色气泡，AI 消息无框纯文字
  • AI 消息支持可折叠的「思考模式」（已思考 X 秒 → 展开查看推理过程）
  • 全屏浅色横幅背景、圆角容器、暗色模式全适配

一、创建数据

1.2 对话数据

新建 source/_data/records.yml，这是全部对话内容的数据库。

字段说明：

字段 说明
title 会话标题，显示在左侧栏
time 会话时间，显示在标题栏右侧
avatar 会话级默认头像（对方）
contents_list 对话消息数组
contents_list[].content 消息正文，支持 YAML `
contents_list[].avatar 可选。有此字段 = AI/对方消息；无此字段 = 用户消息
contents_list[].thinking 可选。AI 消息的思考过程，多行文本
contents_list[].thinking_time 可选。思考耗时（整数秒）

五、设计理念总结

与原始教程的核心差异

原始 meuicat 方案 本方案
布局 <details> 垂直堆叠折叠面板 左侧会话列表 + 右侧聊天区（双栏）
切换方式 浏览器原生折叠 纯 CSS radio 切换（零 JS）
自己消息 绿色气泡 + 头像 + 三角箭头 蓝色气泡，无头像无箭头
对方消息 白色气泡 + 头像 + 三角箭头 无气泡框，仅文字 + 圆形小头像
思考模式 无 <details> 折叠：已思考 X 秒 → 展开推理
横幅 页面顶部卡片 固定全屏背景，opacity 0.06 虚化

为什么用纯 CSS radio 切换

  • 零 JavaScript 依赖
  • 利用 :has() 选择器限定作用域，不影响博客其他页面
  • 利用 ~ 兄弟选择器联动侧栏选中态和主区会话显隐
  • display: none/block 切换无闪烁，配合入场动画

思考模式的 DOM 设计

参考 DeepSeek 网页版结构：

  • Gutter 为 flex column，dot flex-shrink: 0，line flex: 1 自动撑满
  • 灰线从圆点下方 margin-top: 4px 处开始，永不穿透圆点
  • 圆点 margin-top: 5px 对齐第一行文字中心
