# SCHNIE:BLOG

SCHNIE个人博客的静态发布仓库，用于保存文章、学习记录、个人页面及网站资源。

[访问博客](https://blog.sch-nie.com/) · [仓库分类导航](https://github.com/schrolemons)

## 仓库内容

本仓库保存Hexo生成的HTML页面与静态资源。

| 路径 | 内容 |
| --- | --- |
| `index.html` | 网站首页 |
| `posts/` | 文章页面 |
| `archives/`、`categories/`、`tags/` | 文章归档、分类与标签 |
| `about/` | 个人介绍页面 |
| `study/`、`records/`、`essay/` | 学习、记录与随笔相关页面 |
| `css/`、`js/`、`img/`、`vendor/` | 样式、脚本、图片与前端依赖资源 |
| `search.xml`、`sitemap.xml` | 搜索索引与站点地图 |

## 更新方式

文章和主题的修改应在对应的Hexo源工程中完成，生成静态页面后再发布到本仓库。当前仓库根目录保存的是发布产物，不提供独立的Hexo构建配置。

重新发布时请保留本文件，或将本文件纳入源工程的发布产物，以便保留仓库说明。
